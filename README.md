# 📖 About This Repository

This repository documents my journey in becoming a Security Operations Center (SOC) Analyst through hands-on labs and practical investigations.

Instead of only studying cybersecurity concepts, I built a home lab where I configured monitoring tools, analyzed Windows Event Logs, created Splunk detection rules, performed threat hunting, and documented investigations using industry-standard reporting techniques.

Each lab contains:

- Detailed README documentation
- Investigation reports
- Screenshots
- SPL queries
- Observations
- Challenges
- SOC relevance
- Lessons learned

The goal of this repository is to demonstrate practical SOC analyst skills that align with real-world security operations.

---

# 🎯 Learning Objectives

Throughout this project I aimed to:

- Understand Windows logging
- Configure Sysmon
- Deploy Splunk Enterprise
- Collect and analyze Windows Event Logs
- Learn Splunk Search Processing Language (SPL)
- Investigate authentication events
- Perform proactive threat hunting
- Build detection logic
- Conduct incident response investigations
- Improve documentation and reporting skills
